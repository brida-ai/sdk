# Brida SDK

Official open-source client and agent integration surface for Brida.

This repository is currently staged privately while its public-release safety and contract gates are completed.

Planned package: `@brida-ai/sdk`.

The SDK is intended to provide one client across Brida capabilities, beginning with Brida Reflex and later adding product namespaces only when their public contracts are ready.

Public SDK source is an integration surface. Brida's hosted control plane, private product specifications, provider credentials, internal economics and company operations are not part of this repository.

See AGENTS.md before using an AI coding agent in this repository.
